# 01-MICRO-error-001 — HTTP 400（バリデーション · 規約同意）

- **owner**: auto
- **type**: error-code

## 概要

#01 auth router における **400 Bad Request** は、現行 IHL 実装では **規約未同意**（`RegisterRequest.agree_terms == false`）のみ。FastAPI 標準形 `{ "detail": "<string>" }`（単一文字列）が正本。

## 発生 route 一覧

| route | auth | 主な 400 トリガ | detail |
|-------|------|-----------------|--------|
| `POST /api/v1/auth/register` | public | `agree_terms == false`（省略時既定 `false` 含む） | `利用規約への同意が必要です` |

> **関連（本スライス外）**: `magic-link` / `verify` / `session` は **400 を返さない**（verify 失敗は 401 集約 · DET §7 P3）。

## detail 形式

```json
{ "detail": "利用規約への同意が必要です" }
```

- **型**: 常に **string**（`HTTPException(detail=...)`）
- **言語**: 日本語固定（#02 条文本文は触らない · boolean 境界のみ #01）

## ユーザー向け文言（Web）

| detail | 画面 | 表示方針 |
|--------|------|----------|
| `利用規約への同意が必要です` | `/login` register ステップ | チェックボックス未同意を **1 行で具体**に表示 · `role="alert"`（NFR-LOGIN-05 · FR-LOGIN-10） |
| — | magic-link 送信 | クライアント側で同意/メール未入力時は **送信ボタン無効**（API 未到達 · FR-LOGIN-01） |

失敗時: 規約チェックへスクロール · 再送信導線（[`遷移設計-v1.md`](../../遷移設計-v1.md) §3）。

## impl 引用

```89:93:apps/api/routes/auth.py
@router.post("/register")
def auth_register(body: RegisterRequest) -> dict[str, str]:
    if not body.agree_terms:
        raise HTTPException(status_code=400, detail="利用規約への同意が必要です")
    return {"status": "registered", "handle": body.handle}
```
