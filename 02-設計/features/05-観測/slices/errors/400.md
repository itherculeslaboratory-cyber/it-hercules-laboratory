## 概要

観測 API における **400 Bad Request** は、Pydantic 通過後の **ドメイン検証**・**whitelist 違反**・**digest 不一致**・**空 payload** 等で返す。FastAPI 標準の JSON 形 `{ "detail": "<string>" }`（単一文字列）が正本。ユーザー向けは **理由を 1 行で具体**に（OBS-NF-04 · OBS-RX-UX-09）。

## 発生 route 一覧

| route | auth | 主な 400 トリガ | 代表 detail |
|-------|------|-----------------|-------------|
| `POST /api/v1/observation/search` | public | parquet 検索で whitelist 外フィルタ/列 | `Filters not in whitelist: [...]` 等（`QueryValidationError`） |
| `POST /api/v1/observation/measurements` | session | `rows` 空 | `計測行がありません` |

| `POST /api/solid-observation/commit` | session | rows 空 / digest 不一致 / 親参照 / 計測正規化 | 下表「commit 詳細」参照 |

## detail 形式

```json
{ "detail": "計測行がありません" }
```

- **型**: 常に **string**（FastAPI `HTTPException(detail=...)`）
- **言語**: 日本語固定文言 + **機械コード**（`DIGEST_MISMATCH` · `DEVICE_ID_REQUIRED` 等）混在可
- **QueryValidationError**: 英語 `Filters not in whitelist: ['qc_flag']` 形式（`libs/ihl/observation/query.py:68`）

## ユーザー向け文言（Web）

| detail / 系統 | 画面 | 表示方針 |
|---------------|------|----------|
| `計測行がありません` / `計測データがありません` | 入力 · confirm | 「計測を 1 行以上入力してください」 |
| `DIGEST_MISMATCH` | confirm | 「入力内容が変更されました。確認画面からやり直してください」 |
| `未対応の計測方法です` | input / confirm | API `detail` をそのまま（method 名を含む） |
| `PRIOR_CAPTURE_*` | confirm（follow-up） | 「前回観測の参照が無効です。個体を選び直してください」 |
| `TELEMETRY_*` / `DEVICE_ID_REQUIRED` | input env chunk | `formatEnvTelemetryFetchError` — NOT_FOUND は手入力案内（`observation-draft.ts:586-590`） |
| search whitelist | `/observation` 検索 | フィルタを戻す · 500 にしない（UT-05-08） |

confirm 主ボタン失敗時: `setError(ApiError.message)` → StatePanel error（`input/confirm/page.tsx:146`）。
