# 05-MICRO-error-002 — HTTP 401（AUTH_REQUIRED · WRITE 境界）

- **owner**: auto
- **type**: error-code
- **inputs**: WorkOrder `05-MICRO-error-002` · 上記 6 route · [`エラーカタログ-v1.md`](../../エラーカタログ-v1.md) §401
- **acceptance**: 401 の発生条件 · detail メッセージ · UI 導線 · エラーカタログ行 · impl 引用 · テスト参照

## 概要

**Scope A（READ 公開 / WRITE session）** における WRITE 系 route が、環境変数 `IHL_AUTH_REQUIRED=1`（かつ `IHL_AUTH_BYPASS` 無効）のとき **未認証**で叩かれると **401** を返す。detail は常に **`AUTH_REQUIRED`**（機械コード · 日本語化しない）。READ route（search · detail · image · templates GET 等）は **401 にしない**（OBS-GAP-01 · OBS-GAP-03）。

## 発生 route 一覧

| route | 認可の掛け方 | 401 条件 |
|-------|--------------|----------|
| `POST /api/captures` | router 全体 `Depends(enforce_auth_when_required)` | 上記 env ON · session トークン無/無効 |
| `POST /api/measurements` | 同上（solid router） | 同上 |
| `POST /api/solid-observation/commit` | 同上 | 同上 |
| `POST /api/v1/observation/dictionary-extensions` | handler 引数 `RequiredWhenEnabledAuth` | 同上 |
| `POST /api/v1/observation/measurements` | `RequiredWhenEnabledAuth` | 同上 |
| `POST /api/v1/observation/templates` | `RequiredWhenEnabledAuth` | 同上 |

### 401 にならない WRITE（参考 · 本スライス外）

| route | 備考 |
|-------|------|
| `POST /api/v1/observation/upload` | 同型 401 · WorkOrder error-002 inputs 外 · api-016 参照 |
| 全 GET / search POST | Scope A · public READ |

## detail 形式

```json
{ "detail": "AUTH_REQUIRED" }
```

| 項目 | 値 |
|------|-----|
| HTTP status | `401` |
| detail 型 | string · 固定 `"AUTH_REQUIRED"` |
| 追加ヘッダ | なし（WWW-Authenticate 未使用 · IHL session ヘッダ方式） |
| セッション解決 | `X-IHL-Session` または `Authorization: Bearer <token>`（`auth_deps.py:28-37`） |

## 発生条件（環境）

| 変数 | 401 有効化 |
|------|------------|
| `IHL_AUTH_REQUIRED=1` | **必須**（`true`/`yes` も可） |
| `IHL_AUTH_BYPASS=1` | **あれば 401 無効**（dev 用） |
| 既定（未設定） | auth OFF · 401 出ない（テスト既定） |

`auth_is_required()` → `enforce_auth_when_required` が `ctx.required && !ctx.is_authenticated` で raise（`auth_deps.py:67-71`）。

## ユーザー向け文言（Web）

| 状況 | UI 導線 |
|------|---------|
| confirm / input で commit 401 | AppShell が session 欠如を検知した場合は **ログイン Link** へ（エラーカタログ §401 UI 導線） |
| ApiError 401 到達時 | 「ログインが必要です。ログインしてから再度お試しください。」（`detail` をそのまま出さない · 理由は session 不足） |
| READ 画面 | 401 は設計上発生しない · 200/404/empty のみ |

**禁止**: ユーザー向けに `AUTH_REQUIRED` 裸表示のみで終了（ログイン導線必須 · OBS-GAP-03）。

```67:71:libs/ihl/identity/auth_deps.py
async def enforce_auth_when_required(
    ctx: AuthContext = Depends(get_auth_context),
) -> AuthContext:
    if ctx.required and not ctx.is_authenticated:
        raise HTTPException(status_code=401, detail="AUTH_REQUIRED")
    return ctx
```
