# 05-MICRO-error-003 — HTTP 404（リソース不在）

- **owner**: auto
- **type**: error-code
- **inputs**: WorkOrder `05-MICRO-error-003` · 上記 5 route 群 · [`エラーカタログ-v1.md`](../../エラーカタログ-v1.md) §404
- **acceptance**: 404 の発生条件 · detail メッセージ · UI 導線 · エラーカタログ行 · impl 引用 · テスト参照

## 概要

観測 API の **404 Not Found** は、(1) **Truth/テンプレ/画像 blob の不在**、(2) **device registry / telemetry の不在**（solid WRITE）の 2 系統。いずれも `{ "detail": "<string>" }`。GET detail（`GET /api/v1/observation/{capture_id}`）も同型 404 だが、本スライス inputs は WorkOrder 定義の 5 群に限定（detail 行はカタログと共有）。

## 発生 route 一覧

| route | auth | 404 条件 | detail |
|-------|------|----------|--------|
| `GET /api/v1/observation/{capture_id}/image` | public | capture は存在するが blob 無 | `画像がありません` |
| `GET /api/v1/observation/templates/{template_id}` | public | テンプレ ID 不在 | `テンプレが見つかりません` |
| `POST /api/captures` | session | `device_id` が registry 不在 | `DEVICE_NOT_FOUND` |
| `POST /api/captures` | session | env chain · telemetry 無 | `TELEMETRY_NOT_FOUND` |
| `POST /api/measurements` | session | device 不在 / telemetry 無 | `DEVICE_NOT_FOUND` / `TELEMETRY_NOT_FOUND` |
| `POST /api/solid-observation/commit` | session | capture 段階の device/telemetry 不在 | 同上 |

## detail 形式

```json
{ "detail": "capture_id=cap_x の観測データがありません" }
```

| detail パターン | 種別 | 備考 |
|-----------------|------|------|
| `capture_id=… の観測データがありません` | Truth capture | `_load_truth_capture` |
| `画像がありません` | blob | `resolve_image_path` + `image_blob_exists` |
| `テンプレが見つかりません` | テンプレ | event + fixture 両方 miss |
| `DEVICE_NOT_FOUND` | device registry | `DeviceNotFoundError(str)` |
| `TELEMETRY_NOT_FOUND` | env ingest | `ValueError` → 404 にマップ（solid routes） |

## ユーザー向け文言（Web）

| 画面 | 404 系統 | UI 導線 |
|------|----------|---------|
| `/observation/[id]` | capture 不在 | StatePanel empty · タイトルに API detail echo · **観測一覧へ** Link（`[id]/page.tsx:75-80`） |
| 同上 | image 404 | 詳細は表示 · 画像枠に「画像がありません」 |
| input env | `TELEMETRY_NOT_FOUND` | `formatEnvTelemetryFetchError` → 手入力案内（`observation-draft.ts:587-588`） |
| templates 利用 | テンプレ 404 | 「テンプレが見つかりません · 一覧から選び直してください」 |
| device 404 | `DEVICE_NOT_FOUND` | 機器設定 / レジストリ登録へ誘導 |

**一般則**（カタログ §UI）: 404 は **代替導線**（全観測一覧 · 再検索）を必ず示す · 色のみに依存しない。
