## コード別

### 401 AUTH_REQUIRED（WRITE のみ） {#401-auth_requiredwrite-のみ}

| 項目 | 内容 |
|------|------|
| 発生 | `IHL_AUTH_REQUIRED=1` で未ログインが WRITE route を叩く |
| route | upload · measurements · templates(POST) · dictionary-extensions · /api/captures · /api/measurements · /api/solid-observation/commit |
| detail | `AUTH_REQUIRED`（`RequiredWhenEnabledAuth` / router `enforce_auth_when_required`） |
| Scope A | READ（search/detail/image/templates/dictionary/targets/reanalysis）は **401 にしない**（公開） |
| UI 導線 | ログイン Link へ誘導（AppShell） |
| RTM | OBS-GAP-01 / OBS-GAP-03 |

### 400 バリデーション {#400-バリデーション}

| route | 条件 | detail |
|-------|------|--------|
| `POST /api/v1/observation/search` | query whitelist 違反 | `QueryValidationError` 文言 |
| `POST /api/v1/observation/templates` | `target_species` 空 / `rows` 空 | `target_species は必須です` / `rows は1行以上必要です` |
| `POST /api/v1/observation/measurements` | `rows` 空 | `計測行がありません` |
| `POST /api/v1/observation/dictionary-extensions` | `value` 空 / `extension_kind` 不正 | `value は必須です` / `extension_kind が不正です` |
| `POST /api/measurements` | 計測方法未対応 / 行なし | `未対応の計測方法です` / `MEASUREMENT_ROWS_REQUIRED` / `TELEMETRY_EMPTY_READINGS` / `DEVICE_ID_REQUIRED` |
| `POST /api/solid-observation/commit` | digest 不一致 / 計測なし / 親自己参照 | `DIGEST_MISMATCH` / `計測データがありません` / `有効な計測データがありません` / `個体自身を父/母に設定できません` / `PRIOR_CAPTURE_INDIVIDUAL_MISMATCH` |

### 404 不在 {#404-不在}

| route | 条件 | detail |
|-------|------|--------|
| `GET /api/v1/observation/{capture_id}` | capture Truth なし | `capture_id=… の観測データがありません` |
| `GET /api/v1/observation/{capture_id}/image` | 画像 blob なし | `画像がありません` |
| `GET /api/v1/observation/templates/{id}` | テンプレなし | `テンプレが見つかりません` |
| `POST /api/captures` · `POST /api/measurements` | device / telemetry 不在 | `DeviceNotFoundError` / `TELEMETRY_NOT_FOUND` |
| `POST /api/solid-observation/commit` | 同上 + prior capture 不在 | `PRIOR_CAPTURE_NOT_FOUND`（400 扱いの実装あり · 要確認） |

### 409 競合 {#409-競合}

| route | 条件 | detail |
|-------|------|--------|
| `POST /api/solid-observation/commit` | 表示名重複（owner 内） | `同じ表示名が既に使用されています` |

### 201 作成成功（エラーではないが契約明記）

`POST /api/v1/observation/templates` · `POST /api/v1/observation/dictionary-extensions` · `POST /api/captures` · `POST /api/solid-observation/commit`

## UI 一般則（OBS-NF-04 · OBS-RX-UX-09）

- 全 route に **空状態 / エラー / ローディング**を用意（`no-user-facing-unimplemented` 遵守）
- エラーは **理由を短く具体**に表示（1 行 1 情報）· 色のみに依存しない
- 401 は「ログイン」導線、409 は「やり直し」導線、404 は代替導線（全観測一覧へ）
