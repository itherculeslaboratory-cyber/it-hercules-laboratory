## 3. API / route 契約（IHL 実エンドポイント · retrofit）

### 3.1 `GET /api/v1/dispute/{thread_id}`

| 項目 | 契約 |
|------|------|
| 200 | `{ thread_id, dispute_id, status, parties, public_view, messages[], deadline, pt_required, market_dsp_ref? }` |
| `public_view` | **true** = 第三者閲覧可 · 投稿は当事者のみ（FR-DSP-04） |

### 3.2 `POST /api/v1/dispute/{thread_id}/messages`

| 項目 | 契約 |
|------|------|
| body | `{ actor_id, body }` |
| 200 | `{ status: "posted", actor, body(redacted), at }` |
| PII | `redact_pii_text(body)` 適用（FR-DSP-18 方向） |
| 副作用 | `evidence_added` dispute_event 追記 |

### 3.3 `POST /api/v1/dispute/{thread_id}/open-market`

| 項目 | 契約 |
|------|------|
| query | `trade_id`, `actor_id`（dev 既定 `@demo`） |
| 200 | `{ status: "opened", room }` |
| 副作用 | `market_dsp_ref` · `opened` dispute_event |

### 3.9 認証境界（IHL 本番 · 契約オラクル正本）

> **#11 route 集合** — `main.py` dispute 3 本（retrofit スモーク · dev は actor_id 明示可）。

| method | path | auth | 実装 | req |
|--------|------|------|------|-----|
| GET | `/api/v1/dispute/{thread_id}` | **public** | `dispute_room` | FR-DSP-04 |
| POST | `/api/v1/dispute/{thread_id}/messages` | **public** | `dispute_post_message` | FR-DSP-18 |
| POST | `/api/v1/dispute/{thread_id}/open-market` | **public** | `dispute_open_market` | FR-DSP-12 |
