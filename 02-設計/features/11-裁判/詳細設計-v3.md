## 10. 掲示板指摘フロー（REQ §3 → DET 正本）

> **要件 What**: 人間起点の指摘 · 二人部屋 · 合意または TTL 強制クローズ · R2 append-only

### 10.1 入口 UI（FR-DSP-02 · gap）

| 操作 | 契約 |
|------|------|
| 引用 | 通常返信 |
| 指摘 | タグ必須 + 理由必須 → dispute-room create |

**通報ボタン禁止** · NG ワード自動削除禁止（NFR-DSP-01 方向）。

### 10.2 二人部屋（FR-DSP-03/04）

| 項目 | 契約 |
|------|------|
| 参加者 | 指摘者 + 被指摘者のみ投稿 |
| 観覧 | `public_view: true` 時第三者 **閲覧のみ** |
| 重複 | 同一 anchor **open 中は 1 指摘者**（U-MKT-DSP-03） |
| ネスト | 深さ上限なし · 各ネスト独立 R2 記録 |

### 10.3 錨（anchor · U-MKT-DSP-03）

| `anchor_type` | 例 | 可視性 |
|---------------|-----|--------|
| `board_message` | BBS 投稿 ID | 公開観覧可 |
| `listing_engagement` | Q&A/称賛 | 公開観覧可 |
| `trade_private` | `trade_private:{trade_id}` | **非公開** |
| `trade_public_exchange` | 公開エクスチェンジ opt-in | 公開 opt-in |

**1 錨 1 open** — 重複 create は 409（IMPL-GAP · API 未実装）。

### 10.4 合意（FR-DSP-07 · gap）

```text
指摘 → discussing → 修正提案 → 指摘者 OK → 表示切替（新レコード · 旧版削除しない）
  └─ TTL 1 ヶ月（UTC · F11-06=A）→ force_closed（合意なし）
```

**自動合意検知禁止** — 明示操作のみ。

### 10.5 強制クローズとカルマ（§4.1）

- 未解決クローズ累計 · **5 の倍数到達時のみ Δcount +1**（掲示板軸 · #08 正本）
