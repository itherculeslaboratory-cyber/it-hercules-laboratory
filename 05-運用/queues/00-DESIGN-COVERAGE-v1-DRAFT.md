## 4. 機械 vs 人間 — 二重管理の回避

```text
M-083 5 GATE（機械 · 3b 合格正本）
  ├── rtm / reverse-rtm  → TEST+RTM 軸
  ├── layering           → REQ/DET 層分離 + depth/pattern
  ├── parity             → DET ↔ 実装/doc 整合
  └── oracle             → 契約レジスタ

DESIGN-COVERAGE（本草案 · 人間可読）
  └── 「TRN/UI が無い/薄い」等 — GATE が拾わない層の可視化
```

**ルール**: DESIGN-COVERAGE で △ があっても **M-083 PASS なら 3b ブロックしない**（X-07=C）。
