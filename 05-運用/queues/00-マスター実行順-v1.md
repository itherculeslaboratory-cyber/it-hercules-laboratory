## 4.1 Docker 役割 — 人間確定メモ（2026-07-05 · 追記 Go）

> **用途**: 設計書執筆 · contributor 説明 · M-011 / M-010 入力  
> **正本**: [ADR-H-30](../../02-設計/_横断/adr/ADR-H-30-SwitchBot-秘密非保持-v1-DRAFT.md) · [#16 DET](../../02-設計/features/16-UIbuilder/16-UIbuilder-詳細設計-v1.md) · [`docker-compose.yml`](../../docker-compose.yml)

### どこで Docker を使うか（2 ゾーン）

| ゾーン | 役割 | secret | 重い計算 |
|--------|------|--------|----------|
| **ユーザー PC** | 開発 · collector · embedding パイプライン | **SwitchBot 可**（`.env.local` のみ） | **可**（DINOv2 は `[ml]` 追加） |
| **IHL 本番 VPS** | `api` コンテナのみ（512MB） | **SwitchBot 禁止** | **禁止** |

### 確定した 4 点 + SwitchBot

| # | 内容 | 設計整合 |
|---|------|----------|
| 1 | SwitchBot 秘密は **ユーザー PC** の Docker `.env.local` · 本番 VPS の `api` には載せない | ADR-H-30 STRONG |
| 2 | 写真 **Embedding** 等は **ユーザー PC** の Docker / pipeline で負担 · サーバは API のみ | #18 · `components/embedding_builder` |
| 3 | **Web UIbuilder** = 簡易（部品選び · 配置 · 保存）· 詳細 IDE 的作業 = **repo + dev 環境**（Docker IDE 製品は **未設計** · legacy salvage のみ） | ADR-H-01 REFRAME |
| 4 | **機能開発 = GitHub（PR）** · UIbuilder では新 API / 新 Component を作らない | #16 DET §5.1 OUT |
| **+** | **SwitchBot 機器の自動取り込み**（LAN poll → Tier B ingest）は **ユーザー PC で Docker `collector` 必須** · secret は PC のみ · IHL サーバ構成要素ではない | ADR-H-30 経路 C · `docker compose --profile collector` |

### SwitchBot 取り込み経路（v1 · 混同禁止）

| 経路 | Docker | secret | 正本 |
|------|--------|--------|------|
| **A 手動 Export → Import** | 不要 | 不要 | ADR-H-30 §2.1 A · UI/CSV upload |
| **B 観測時手入力** | 不要 | 不要 | ADR-H-30 §2.1 B |
| **C 自動 poll → ingest** | **ユーザー PC で必須**（`collector`） | PC の `.env.local` のみ | ADR-H-30 §2.1 C · [`collector/`](../../collector/) |

> **却下**: IHL VPS / 本番 `api` コンテナでの SwitchBot poll（ADR-H-29 サーバ poll 却下 · ADR-H-30）

### compose profile 早見（M-011 執筆入力）

| profile | 主用途 | 実行場所 |
|---------|--------|----------|
| `api` | FastAPI :8000 · schema マウント | dev: PC · 本番: VPS |
| `web` | Next :3000 | dev PC（本番 VPS 同居禁止） |
| `test` | pytest 再現 | CI / dev PC |
| **`collector`** | **SwitchBot poll → ingest** | **ユーザー PC のみ** |
| `search` | Streamlit 観測検索 dev :8501 | dev PC |

│ docker collector ───────┼─ingest─►│ secret なし      │
