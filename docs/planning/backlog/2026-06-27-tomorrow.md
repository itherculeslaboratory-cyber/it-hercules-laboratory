## 明日やること 2: 観測検索スコープ

### 症状

- ユーザー報告: 検索結果が **自分のアカウントに紐づく観測だけ** に見える。期待は **より広い結果**（公開カタログ等）の可能性

### 現状コードの挙動

#### フロント（観測検索）

- `apps/web/src/hooks/useObservationSearch.ts` → `POST /api/v1/observation/search` に `{ limit, species, sex, stage_name, view_type }` のみ送信
- **`owner_user_id` / `actor_id` は検索リクエストに含めない**

#### バックエンド

- `apps/api/routes/observation.py` `observation_search`
  - `ALLOWED_FILTERS`（`libs/ihl/observation/query.py`）= `species, sex, stage_name, view_type, individual_id, capture_id` — **`owner_user_id` なし**
  - parquet + Truth event store を **マージして全件返す**（セッションの actor で絞り込み **しない**）
  - router 全体に `enforce_auth_when_required`（`IHL_AUTH_REQUIRED=1` 時は 401 のみ・スコープ変更なし）

#### 関連だが別 API（混同注意）

- 観測**入力**・個体・命名・環境 IoT はフロントが **`owner_user_id: "u_demo"` / `actor_id: "u_demo"` をハードコード**（セッション `actor_id` 未連携）
  - `observation/input/page.tsx` · `input/confirm/page.tsx` · `individuals/[id]/page.tsx` · `settings/devices/page.tsx` 等
- 個体検索 `GET /api/v1/individuals/search?owner_user_id=u_demo` は **明示的に owner フィルタ**

#### データモデル

- `searchable_capture_set` parquet ホワイトリスト（`query.py` `ALLOWED_COLUMNS`）に **`owner_user_id` 列なし**
- 計測テンプレのみ `visibility: private|public`（`ObservationTemplateCreateRequest`）— **capture 検索への反映は未実装**

### 「自分の観測だけ」に見える想定原因

1. **VPS の Truth/R2 が単一テナント相当** — 実データがそのユーザーの commit のみ
2. **フロント commit が `u_demo` 固定** vs ログイン `actor_id`（hash）の **データ分断**
3. ユーザー期待が **コミュニティ公開カタログ** で、現 API は **インフラ上グローバルだがプロダクト上スコープ未定義**

### 要確認事項（人間判断）

1. 検索の正しいスコープはどれか？
   - **A**: ログイン利用者の **自分の観測のみ**（現状は API 未実装・データ偶然一致）
   - **B**: **公開（visibility=public）** された観測のカタログ
   - **C**: **全登録観測**（テナント横断・研究カタログ）
2. `owner_user_id` を capture / parquet / Truth に **永続化するか**（スキーマ拡張）
3. 本番 VPS に **他ユーザーの観測データが存在するか**（存在しないなら UI 以前のデータ問題）
4. `IHL_AUTH_REQUIRED` と検索スコープの組み合わせ（未ログイン閲覧可否）

### 候補方針（実装前のたたき台）

| 方針 | 概要 | タッチ箇所 |
|------|------|------------|
| **P1 セッション連携** | フロントの `u_demo` を `GET /api/v1/auth/session` の `actor_id` に置換。commit / 個体 / 命名をログインユーザーに紐付け | `input/*` · `useAuthSession` · solid commit body |
| **P2 検索スコープ API** | `observation_search` に `scope: mine \| public \| all`（または query `owner_user_id`）· セッション actor でデフォルト `mine` | `observation.py` · `query.py` ALLOWED_FILTERS/schema · `useObservationSearch` |
| **P3 公開フラグ** | capture commit 時に `visibility` 保存 · parquet 投影に `owner_user_id` + `visibility` 追加 | `solid_commit` · schema · pipeline |
| **P4 UI** | 検索画面にスコープ切替（「自分のみ / 公開カタログ」）チップ | `observation/page.tsx` |

**推奨着手順**: 人間がスコープ方針確定 → **P1**（データ分断解消）→ **P2/P3**（意図したフィルタ）→ E2E
