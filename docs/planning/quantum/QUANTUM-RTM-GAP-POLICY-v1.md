# QUANTUM RTM gap 整理方針

> **生成**: QUANTUM レーン D · 2026-07-03

RTM の `gap` / `planned` / `deferred` 行は **粉飭せず** 次のいずれかを付与する:

| 対応 | 条件 |
|------|------|
| **TC ID 付与** | IMPL 波で pytest 追加予定 |
| **`human` + 理由** | 法務 · live 入金 · 打鍵 |
| **`deferred` + ver** | ver5+ 機能（段階リリース計画 §4.1） |

MAD 時点の gap 行は設計追跡ラベルとして **正当に残存**。QUANTUM は screen/payload/infra の粒設計を追加し、gap 実装は **DELEGATED-IMPL-GO 後**。
