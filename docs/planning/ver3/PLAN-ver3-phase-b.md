## 7. 想定リスク

0. **夜間運転のコスト暴走**: 無人実行はトークン/API 費が見えにくい → 1夜あたりの上限予算・実行時間上限・成果ゼロ時の自動停止をルーチン定義に必須で入れる（『一日で20ドルかかった』の再発防止）。
1. **外部調査の鮮度**: 2026-07 時点情報。B2 成果物に調査日を明記し、実装着手時に再検証条項を付ける。
2. **裁定保留の累積**: G2/G3 で保留が多いと B1 の確定範囲が痩せる → 保留要件は DRAFT 節に隔離し、確定分だけで B3 以降を進められる構成にする。
3. **W2 再開判断の複雑性**: ui-parts-lab-w2 資産・QUANTUM 1813シャードとの整合が必要 → B3 で「再開/作り直し/廃棄」の3案比較で提示。
4. **英語版の陳腐化**: 日英同時更新は運用負荷 → 日本語を正本、英語は各成果物確定時に一括生成と規約化。
