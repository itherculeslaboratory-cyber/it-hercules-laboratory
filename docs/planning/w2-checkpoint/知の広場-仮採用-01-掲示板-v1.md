## §DET 将来詳細設計

### DET-KN-01 データモデル（イベント · 投影）

#### 1.1 識別子規約（仮採用）

| フィールド | 形式 | 発行 | 備考 |
|------------|------|------|------|
| `thread_id` | `thr_{ulid}` | `board_store.create_thread` | スレッド不変 ID · URL 正本 |
| `post_id` | `pst_{ulid}` | **新規追加（ギャップ）** | 現行 `board_store.append_post` は **post_id 未発行** — 本採用時に event payload へ追加 |
| `board_kind` | enum | 正規化 | `gripe` · `improve` ·（論文 `paper_case` · その他 `other` は xref） |
| `category` | API パス用 | 表側 | `rant`↔愚痴 · `general`↔改善/その他 — **ルート `/board/gripe` とのマッピング要整理** |

#### 1.2 board event（INSERT ONLY 正本）

```json
{
  "kind": "thread_create | post_append | pointer",
  "board_kind": "gripe | improve | ...",
  "category": "rant | general | ...",
  "thread_id": "thr_...",
  "post_id": "pst_...",
  "title": "（thread_create のみ）",
  "actor_id": "usr_...",
  "body": "（post_append のみ）",
  "case_chip": null,
  "dispute_kind": null,
  "created_at": "ISO8601"
}
```

- **訂正**: 新しい `post_append` で訂正文を追記。既存 event の mutation 禁止。
- **pointer**: 指摘開始時の錨イベント（#11 連携 · optional v1）。

#### 1.3 スレッド index 投影（読み取りモデル）

| 投影フィールド | ソース event | 用途 |
|----------------|--------------|------|
| `thread_id` | thread_create | URL · 一覧キー |
| `title` | thread_create | 一覧タイトル |
| `post_count` | post_append 集計 | 「N レス」 |
| `last_activity` | 最新 post/thread の `created_at` | ソート |
| `board_kind` | thread_create | 板フィルタ |

#### 1.4 投稿 projection（読み取りモデル · post_id 追加後）

| 投影フィールド | 備考 |
|----------------|------|
| `post_id` | アンカー `>>N` は **表示番号**（1-origin）と `post_id` の二重管理を避けるため、UI は表示番号、API は `post_id` |
| `response_no` | スレ内連番（1 = スレ立て本文） |
| `actor_id` / `display_name` | 愚痴板は display_name 省略可 |
| `body` | Markdown subset（SHOULD · 未決） |
| `quoted_post_id` | 引用元（optional） |

### DET-KN-04 INSERT ONLY 運用規則

1. **DELETE / PATCH エンドポイントを追加しない**（NFR-BBS-01）。
2. モデレーションは **追記**（「削除済みとしてマーク」event）または **指摘→二人部屋**（#11）。
3. index は **イベント再投影** — ミュータブルな RDB 行を正本にしない（DET v3 §4）。
4. GitHub + R2 が改善履歴の監査正本（legacy C-Sync **不採用**）。

### OSS-KN-03 移植手順（仮）

1. 5ch-browser-template を **read-only 参照** clone（submodule 化しない — スナップショットコピー可）。
2. MIT 部分のみ抽出: HTML 構造 · CSS 変数 · アンカー番号ロジック。
3. React + shadcn に置換 — **jQuery 依存は持ち込まない**。
4. IHL トークン（`#0D0D0D` / `#C9A227`）で再スタイル。
5. `BoardPost` API を拡張（`responseNo` · `anchorMap`）— catalog 変更は W2 パッチ経由。

### OSS-KN-04 GPL 回避リスト（採用禁止 · 参考のみ）
