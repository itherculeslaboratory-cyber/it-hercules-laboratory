# IHL 用語彙 v1（狂気モード基盤 · 横断）

> glossary-1term スライスの集約先。DET / REQ / RTM で同じ語を同じ意味で使うための正本。

---

| 用語 | 定義 | 主な出現 |
|------|------|----------|
| **capture** | 1 回の観測イベント（`cap_*`）。写真・計測・環境点を束ねる Truth の単位 | `capture/capture` · `capture_id` |
| **individual** | 個体（`ind_*`）。複数 capture を時系列で持つ。命名・親子連携の主体 | `individual_id` · naming/parent_link |
| **Truth** | append-only の正本イベントストア（R2 INSERT ONLY）。`truth/capture/capture/<id>.json` | `r2Key` · event_store |
| **Scope A** | コミュニティ READ 公開スコープ。検索/詳細/画像等は未ログイン可。**WRITE のみ** session 必須 | OBS-GAP-01/03 · DET §3.9 |
| **binding moment** | `POST /api/solid-observation/commit`。capture + 計測 + 派生（Occupancy/DeviceBinding）を確定する瞬間 | observation_solid.py |
| **derived binding** | commit 時に placement/devices から派生する Occupancy・DeviceBinding INSERT | derive_bindings.py · `trigger_capture_id` |
| **measurement** | 計測行（`measurement_name` · `value_origin` · `method`）。手入力 or iot_switchbot | capture/measurement |
| **value_origin** | 計測値の由来。`direct_observed`（手入力）/ `environment_derived`（IoT 派生） | OBS-RX-REP-07 |
| **photo_conditions** | 撮影時条件（照明/照度レベル等）。写真あり時のみ。`environment_snapshot` とは**分離**（B モデル） | ADR-H-36 |
| **environment_snapshot** | 観測時の環境点（温度/湿度）。写真なし時のみ commit（B モデル） | ADR-H-36 |
| **clientContentDigest** | commit body の canonical ハッシュ。サーバ再計算と不一致なら `DIGEST_MISMATCH`(400) | OBS-RX-REP-05 |
| **placement** | 設置（飼育棚等）。devices と個体の関連付け起点 | PlacementStore |
| **template（計測テンプレ）** | 計測項目セットの再利用単位。LIST/DETAIL 公開・保存は session | OBS-TPL-16/17 |
| **RequiredWhenEnabledAuth** | `IHL_AUTH_REQUIRED=1` 時のみ session を要求する依存。WRITE route に付与 | auth_deps.py |
| **契約レジスタ** | routes から自動生成する API 契約 YAML の機械正本。DET §3.9 と突き合わせ | 契約レジスタ-v1.yaml |
| **逆RTM** | test_case_id → req_id の逆引き表。孤立 TC 検出用 | 逆RTM-v1.csv |
| **MICRO スライス** | 1 route/モデル/エラー/req_id まで分解した作業票の1単位 | WorkOrder-NN-MICRO.json |

---

> 追加は glossary-1term スライスで。定義変更は DET/REQ 側と同時更新（層分離）。
